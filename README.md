# CineMaster-Android
A cinema ticketing Application for Android Operating System

CineMaster is a simple Android cinema ticket booking application. Users will be able to browse movies, select a date and showtime, choose available seats and create a digital ticket. The project is also intended to bring together knowledge from previous modules, including Object-Oriented Programming, Software Development, System Design and Concurrent Development, while applying Android-specific features such as GPS, intents and local persistent storage.
